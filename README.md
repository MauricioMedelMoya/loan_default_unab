# Loan Default Prediction

Proyecto de Machine Learning orientado al análisis exploratorio y modelado predictivo del incumplimiento de préstamos.

## Estructura
- `data/raw/`: datos originales
- `data/processed/`: datos procesados
- `notebooks/`: notebooks del análisis
- `src/`: código auxiliar
- `reports/`: resultados y visualizaciones

python -m venv .venv
source .venv/bin/activate
